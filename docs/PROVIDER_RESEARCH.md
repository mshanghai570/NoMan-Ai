# Provider research notes

These notes preserve the official documentation used to shape the adapter boundary. Policies and model availability can change; re-check the linked source before enabling a provider in production.

## Architecture conclusions

- SpicyChat is a first-party account-based website/app. Its current official docs do not publish a supported developer API, auth contract, webhook, or job protocol. Do not scrape, automate, proxy, or present it as a backend provider. Use only a user-facing link or a future authorized partner API.
- Kilo Gateway is an OpenAI-compatible text/chat API with synchronous JSON and SSE streaming. It is suitable for roleplay, agent-mode prompt bundles, memory summaries, and scene prompts. Kilo is not documented as a general image/video generation backend. Free/Auto Free routing is rate-limited and provider policy still applies; it should not be labeled uncensored or guaranteed for explicit content.
- Leonardo, Replicate, and BytePlus ModelArk expose documented authenticated media APIs with asynchronous job flows suitable for an internal normalized job contract. Leonardo image/image-to-video and Replicate predictions use IDs with polling/webhooks; BytePlus Seedream image generation is direct/streaming while Seedance video uses a task ID and retrieval endpoint.
- Cloudflare Workers AI is a constrained image adapter for documented models such as FLUX.1 Schnell. Its REST API can return a binary/Base64 image; the separate batch API is not a universal video contract.
- Pollinations exposes direct image/video routes and a live model catalog. Model capabilities, authentication, safety, and community-provider terms vary, so the app should wrap it in guarded configuration rather than claim unlimited/no-policy behavior.
- Perchance publishes a browser-oriented image API example, but its current Terms prohibit automated/non-human access and do not document a stable auth, quota, webhook, or general media contract. Treat it as experimental/custom only after permission is clarified.

## Perchance follow-up (2026-11-12)

The official `pretty-ai-video-generator` page documents a browser workflow for text-to-video and image-to-video. It describes prompt, optional timeline, style, negative prompt, aspect ratio, frame rate, duration, seed, batch queue, and WebM/MP4/GIF exports, but it does not publish a stable server API or webhook contract. The official `aichat` page currently redirects users toward a newer fork and likewise does not expose a documented API contract.

The official `perchance-ai-api` page is dynamic and returned only a short live-status marker through static extraction. Interactive inspection and the public integration example confirm that the supported external contract is a browser iframe with query parameters such as `prompt`, `format=json`, `id`, `resolution`, `guidanceScale`, `seed`, and optional `negativePrompt`; the result is delivered via `postMessage` with the `perchance-image-api` marker and a hosted image URL. It is therefore implemented as a browser provider, not as a server-side Custom JSON adapter. Search-result text alone is not enough to establish a supported server integration.

The current official Terms page says users must be 18+, and its FAQ says generated outputs may be used commercially; the same page contains broad service/content-use restrictions and permits the platform to change terms. This supports importing user-generated files or using the documented iframe API, but does not authorize scraping internal browser endpoints or presenting undocumented calls as a stable provider API. The public reverse-engineered integration material also describes internal verification, access-code, and Turnstile flows; those are deliberately not used by NoMan AI.
